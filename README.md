# אור — כוונה בתפילה

דף נחיתה עצמאי בעברית וב־RTL של **פרויקט אור**, עבור המפגש **„כוונה בתפילה”**.

הפרויקט קשור לעולם התוכן של הספר והאפליקציה „מדיטציה בתפילה”, אך נשמר כריפו עצמאי לצורך אתר הקורס.

## GitHub Pages

האתר מתפרסם אוטומטית מ־`main` באמצעות workflow בתיקייה `.github/workflows`.

בגרסת GitHub Pages טופס ההרשמה מוצג במצב „בקרוב” עד לחיבור יעד הרשמה חיצוני. בהרצה עם `server.js` הטופס נשמר מקומית דרך `/api/register`.

## הפעלה

```bash
npm start
```

לאחר מכן פותחים: <http://localhost:8088>

ההרשמות נשמרות מקומית בקובץ `leads/registrations.jsonl` שאינו נכנס ל־Git.

אפשר לשנות כתובת האזנה ופורט באמצעות `HOST` ו־`PORT`.
